# 对方安装说明（DSH 消息插件）
<!-- The version and the package name below are filled in by scripts/build-package.sh when the package is built. -->

> 你收到了 `chat-room-{{VERSION}}.tgz`。假设 DSH 已经装好，**整个过程只需要 1 次授权**：
> 上传插件包 + 说一句话 → 批准那一次 → 粘贴添加码。

## 第 1 步：装插件（1 次授权）

1. 在电脑上打开 **DSH（DeepSeek Harness 桌面版）**，版本和对方一致。
2. 把 `chat-room-{{VERSION}}.tgz` 直接**拖进 DSH 的输入框**（或点附件按钮选它）。
3. 在同一个输入框里说这一句（照抄即可）：

   ```
   用 plugin_manager 安装我刚上传的 chat-room-{{VERSION}}.tgz，只调用 plugin_manager 这一步，不要执行其它命令
   ```

4. DSH 弹出一次授权（danger-full-access）→ 点「**允许一次**」。
   这是**唯一**一次授权：这个插件没有依赖、不会跑任何安装脚本，只是把插件装进你的 DSH。
5. 装好后左侧边栏会多一个「消息」图标。

### 如果 DSH 说没有 plugin_manager 工具

`plugin_manager` 工具默认只在 **Creator 模式**开启：

- 点 DSH 右上角的模式选择器（截图里「标准模式」那个下拉），切成 **Creator 模式**，再把上面那句话发一次；
- 或者在「设置 → 插件」里把 `plugin_manager` 工具打开。

**没有这个工具时不要让 AI 自己找别的办法**（比如跑 `dsh --dump-config` 之类的命令）——那类命令会改写你的 profile 配置，而且每一步都要你单独授权。

### 不想上传 tgz 的备选

用 zip 也行，但要自己先解压（Finder 双击即可），然后说：

```
用 plugin_manager 安装 <解压后的目录绝对路径>，只调用 plugin_manager 这一步
```

## 第 2 步：加对方（粘贴添加码）

1. 点左侧「**消息**」图标。
2. 点右上角「**+**」→「**添加联系人**」。
3. 把对方发给你的**添加码**（`DSHCHAT2:` 开头的一整行）粘进去，点「添加」。
4. 联系人出现在左侧列表，点开就能聊。

> 对方之前用的是旧版插件、给的是 `DSHCHAT1:` 开头的房间码，同样可以粘贴。

## 从旧版本升级到 {{VERSION}}（你现在是 1.2.2）

1.2.2 还不支持自动更新，所以**先手动升级这一次**：

1. 把 `chat-room-{{VERSION}}.tgz` 拖进 DSH 输入框；
2. 说：`用 plugin_manager 安装我刚上传的 chat-room-{{VERSION}}.tgz，只调用 plugin_manager 这一步，不要执行其它命令`
3. 批准一次授权。

升级后你的插件就会自己检查更新了——只要把我的添加码加进去（这一步你本来就要做），更新地址会一起带过去，以后我发新版本你自己点一下就行。

**不用重新互加联系人**：1.2.2 和 1.4.0 的消息协议是同一个，升级后原来的人还在，聊天的记录也都还在。

## 以后我怎么升级插件（1.5.2 起不用再找我了）

**1.5.5 起插件会自己查更新**：发布版自带更新地址，装上就知道去哪找新版本，**不用填任何东西**。

以后我发新版时：它每 30 分钟自己查一次，有新版就在**齿轮和侧栏「消息」图标上亮红点**，你点一下「立即更新」就换好，**不用重启 DSH**，联系人、聊天记录、添加码都原样保留。

（在「消息」→齿轮→「插件更新」里可以看到「当前使用：」的实际更新地址；想换成别的地址也可以自己改。）

下面是给还没用上这个功能的版本的旧办法：

**如果你装的是 1.4.0 或更新版本**：插件会自己检查更新——你在「我的设置 → 插件更新」里填过一次更新源（我给你的添加码里就带着），有新版本时消息面板顶部会出现「发现新版本 x.y.z」，点「立即更新」就行，**不用再找我要文件，也不用重启 DSH**。

下面是给还没用上这个功能的版本的旧办法：

我发新版本时，**文件名会带新版本号**（我刚发的是 `chat-room-{{VERSION}}.tgz`）。你照旧做就行：

1. 把新的 `.tgz` 拖进 DSH 输入框；
2. 说同一句：`用 plugin_manager 安装我刚上传的 chat-room-{{VERSION}}.tgz，只调用 plugin_manager 这一步，不要执行其它命令`；
3. 批准一次授权。

**注意一定要用新文件名**：同名文件重复安装会被判定成「已安装」，不会更新。装完**立即生效，不用重启 DSH**。

## 为什么之前会要很多次授权

如果你之前收到的提示是一长串 `danger-full-access`，多半是下面两条原因叠加：

1. **当时在「标准模式」**，DSH 里没有 `plugin_manager` 工具，AI 只好自己找命令行办法，于是去跑 `dsh --dump-config` 这类命令——那会**重写 profile 的 `cordis.yml`**，而且每条命令都要你批一次。
2. **插件包是 zip**，AI 需要先解压（要 shell 工具、要写文件），解压路径还得自己猜，于是开始"深度搜索"，每一步探索都是一次授权。

现在改成 `.tgz` + 一句确定的口令（只调用 `plugin_manager`、不要执行其它命令），就只剩「安装插件」这**一次**授权了。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 侧边栏没有消息图标 | 「设置 → 插件」里找到「消息」，关掉再打开一次；仍不出现就重启 DSH |
| 「添加码无效」 | 确认把 `DSHCHAT2:` 开头的整行都复制了，没有漏字符 |
| 状态一直「连接中…」/「连接异常」 | 检查网络能否访问 `ntfy.sh`；添加码里的中继地址要和对方一致 |
| 发消息失败 | 公共中继有每日条数/频率限制，稍等再发；长期聊天建议双方换自建中继 |
| 收不到对方消息 | 双方都要**同时开着 DSH**；不是离线留言，对方关掉 DSH 就收不到 |
| 想改名/删联系人 | 点开对话右上「信息」：可以改备注名、清空记录、删除联系人 |

## 第一次用建议先改昵称

装好后点左下角齿轮，把自己的昵称改成好认的名字（比如「小明」）。在你改之前，你的名字显示为 `用户-xxxx`；对方给你发消息时，联系人列表里出现的是「未命名联系人 + 未设置昵称」，这是正常的——改完昵称后，对方那边再收到你的消息就会显示你的名字。

## 隐私提醒

添加码就是你的收件地址：**拿到它的人都能给你发消息**，所以只发给想聊的人，不要公开发布。中继服务器（默认 `ntfy.sh`）能看到消息明文，最多缓存 12 小时；插件本身不在服务器保存任何聊天记录。
